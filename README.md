# Schemi elettrici

Archivio degli schemi elettrici e dei progetti delle PCB del reparto di Elettronica.

## Progetti

### *Neverina*
Schemi elettrici per le schede dell'Unità Centrale di Neverina. Nel corso della stagione 2025-2026, sono state sviluppate e realizzate due differenti istanze del progetto
 - schema elettrico originale, realizzato su *perf-board* in giugno 2026
 - prototipo di PCB, realizzato in settembre 2026.
